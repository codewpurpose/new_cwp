# CodeWithPurpose website design

Keep the existing CodeWithPurpose content, section order, destinations, and navigation across the marketing site and learning platform. The shared palette is warm sand, paper, ink, and moss, with Radix Grass tokens for small leaf-green accents. Use the current type pairing: Archivo for body and controls, Fraunces for expressive display headings, and Spline Sans Mono for code and technical labels. Fredoka stays as the homepage-only accent face for Koda's greeting.

Preserve impact figures, course links, stories, media, FAQs, calls to action, footer links, account actions, lesson content, and existing routes. Simplify visual weight with open layouts, quiet separators, and fewer card surfaces. Keep the existing responsive behavior and form interactions. Use Base UI for accessible interaction primitives and Motion for brief, purposeful transitions. Koda can cycle through poses on click, float gently, and use a brief entrance motion. Respect reduced-motion preferences and keep content readable if client-side motion does not run.

Apply the shared light theme, typography, and restrained interaction motion across every route. Keep each page's existing information, layout purpose, and functionality; the learning readers retain their specialised chart, code, and lesson components.
